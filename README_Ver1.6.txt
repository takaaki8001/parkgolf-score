パークゴルフ スコア帳 Ver.1.6

【導入】
ZIPを展開し、index.html / 各 .js / sw.js / manifest.webmanifest / アイコンを
同じ階層で GitHub Pages のリポジトリへアップロードしてください。
ホーム画面のアプリはService Workerの更新後、再起動や再読み込みが必要な場合があります。

【主な変更】
・上部メニュー：プレー／コース／記録／プレイヤー／データ管理
・「コースの登録・編集」「プレイヤーの登録・編集」へ見出しを変更
・プレイヤーIDの統合（同じラウンドに両方がいる場合は安全のため拒否）
・日付で記録をまとめて選択、テキスト・JSON・PNGで共有
・共有テキスト貼り付けまたはJSONファイルから複数記録を一括取り込み
・プレイヤー対応付け、重複した共有IDの自動スキップ
・全データのバックアップと復元を「データ管理」に移動
・「順番じゃ」を「順番です」に修正

【重要な注意】
・この版はVer.1.5のローカル保存キーを維持しています。
・初回更新前にVer.1.5からバックアップを保存することを推奨します。
・共有データの取り込みは「追加」、全データのバックアップ復元は「置き換え」です。
・写真はIndexedDBに保存され、従来通りバックアップには含まれません。
・テキスト共有は長文になることがあります。LINEへの貼り付けと受信を実機で確認してください。
・プレイヤー統合は取り消せません。必ず事前にバックアップを取ってください。
・初回実地検証前のビルドです。実データでの試験はバックアップの上で行ってください。
